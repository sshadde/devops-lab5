# Основные команды Linux

## Навигация
- `pwd` - показать текущий каталог
- `ls` - показать содержимое каталога
- `cd` - перейти в каталог

## Файлы и каталоги
- `mkdir` - создать каталог
- `touch` - создать файл
- `cp` - копировать
- `mv` - переместить или переименовать
- `rm` - удалить

## Поиск 
- `find` - найти файлы
- `grep` - найти строки по шаблону

## Права доступа
- `chmod` - изменить права доступа

## Процессы
- `ps` - показать процессы
- `kill` - завершить процесс
